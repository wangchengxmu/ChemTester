## Partition Function Magnitudes

### Typical Values at 298 K

| Type | Magnitude | Example |
|------|-----------|---------|
| q_trans (per liter) | 10²⁸ - 10³² | Depends on mass |
| q_rot | 10 - 1000 | N₂ ≈ 52, I₂ ≈ 2800 |
| q_vib | 1 - 2 | Usually ≈ 1 |
| q_elec | 1 - 3 | Ground state degeneracy |

### Example: N₂ at 298 K, 1 L

```
Mass = 4.65 × 10⁻²⁶ kg
V = 10⁻³ m³

q_trans = (2πmkT/h²)^(3/2) × V
        ≈ 1.9 × 10³¹

q_rot = T/(Θ_rot × σ)
      = 298/(2.88 × 2)
      ≈ 52

q_vib = 1/(1 - exp(-Θ_vib/T))
      = 1/(1 - exp(-3393/298))
      ≈ 1.00003

q_total = q_trans × q_rot × q_vib
        ≈ 9.9 × 10³²
```

## Low and High Temperature Limits

### Rotational Partition Function

**Low T (T << Θ_rot):**
```
q_rot ≈ 1 + 3 exp(-2Θ_rot/T)
```
Only J = 0 and J = 1 significantly populated.

**High T (T >> Θ_rot):**
```
q_rot = T/(Θ_rot × σ)
```
Classical limit, integral approximation valid.

### Vibrational Partition Function

**Low T (T << Θ_vib):**
```
q_vib ≈ 1
```
Ground state only.

**High T (T >> Θ_vib):**
```
q_vib ≈ T/Θ_vib
```
Classical limit.

## Quantum Numbers and Degeneracies

### Translational

```
n_x, n_y, n_z = 1, 2, 3, ...
E = h²(n_x² + n_y² + n_z²)/(8mL²)
```

Degeneracy: Depends on sum n_x² + n_y² + n_z²

### Rotational (Diatomic)

```
J = 0, 1, 2, ...
E_J = J(J+1)h²/(8π²I)
g_J = 2J + 1
```

### Vibrational (Harmonic Oscillator)

```
v = 0, 1, 2, ...
E_v = (v + ½)hν
g_v = 1 (non-degenerate)
```

## Practical Calculation Tips

### When to Use Discrete Summation

1. **Rotational:**
   - T < 2Θ_rot: Use explicit sum
   - T > 10Θ_rot: Integral approximation OK

2. **Vibrational:**
   - Always use sum (closed form exists)
   - Never need numerical integration

### Numerical Stability

1. **For large energies:**
   ```python
   # Bad: exp(-E/kT) when E >> kT
   # Good: use log probabilities
   
   log_P = -E/(k*T) - log(Z)
   ```

2. **For partition functions:**
   ```python
   # Sum largest terms first
   energies = sorted(energies)  # ascending
   # Or use log-sum-exp trick
   ```
