## 5. Quick Reference: Choosing the Right Reagent

### 5.1 Alcohol → Carbonyl Selection Guide

| Goal | Best Reagent | Alternative |
|------|-------------|-------------|
| 1° alcohol → aldehyde (general) | DMP or Swern | PCC, TEMPO/NaOCl |
| 1° alcohol → aldehyde (acid-sensitive) | Swern or DMP | TEMPO/NaOCl |
| 1° alcohol → carboxylic acid | Jones or TEMPO/NaOCl (excess) | KMnO₄, PDC (CH₂Cl₂) |
| 2° alcohol → ketone (general) | DMP or PCC | Swern, Jones |
| 2° alcohol → ketone (acid-sensitive) | DMP or Swern | TPAP/NMO |
| Allylic alcohol → aldehyde | MnO₂ or DMP | PCC |
| Benzylic alcohol → aldehyde | MnO₂ or DMP | PCC, TEMPO |
| Large scale / industrial | TEMPO/NaOCl | Jones (cheap) |

### 5.2 Carbonyl Reduction Selection Guide

| Goal | Best Reagent | Alternative |
|------|-------------|-------------|
| Aldehyde → 1° alcohol | NaBH₄ | LiAlH₄ |
| Ketone → 2° alcohol | NaBH₄ | LiAlH₄ |
| Ester → alcohol | LiAlH₄ | DIBAL-H then NaBH₄ |
| Ester → aldehyde | DIBAL-H (-78°C) | Rosemnund (via acid chloride) |
| Carboxylic acid → alcohol | LiAlH₄ | BH₃·THF |
| Amide → amine | LiAlH₄ | BH₃·THF |
| Amide → aldehyde | DIBAL-H (careful) | Red-Al (partial) |
| Ketone + chiral ligand → chiral alcohol | Noyori asymmetric | CBS reduction |
| Ketone → alkane | Wolff-Kishner or Clemmensen | Mozingo (thioacetal) |

### 5.3 Alkene Transformation Selection Guide

| Goal | Best Reagent | Alternative |
|------|-------------|-------------|
| Alkene → epoxide (electron-rich) | mCPBA | DMDO (mild) |
| Alkene → epoxide (enantioselective) | Sharpless (allylic alcohol) or Jacobsen | Shi epoxidation |
| Alkene → cis-diol | OsO₄/NMO | KMnO₄ (cold, dilute) |
| Alkene → cis-diol (enantioselective) | Sharpless AD | OsO₄ with chiral ligand |
| Alkene → aldehyde(s) | Ozonolysis + reductive workup | OsO₄/NaIO₄ |
| Alkene → carboxylic acid(s) | Ozonolysis + oxidative workup | KMnO₄ (hot) |
| Alkene → alkane | H₂/Pd-C | H₂/Raney Ni |
| Alkyne → cis-alkene | Lindlar catalyst | P-2 Ni (Ni₂B) |
| Alkyne → trans-alkene | Na/NH₃ (Birch) | Li/NH₃ |
