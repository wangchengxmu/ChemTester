## 10. Notes on Usage

### Hammett Equation Variants

1. **Standard Hammett:** log(k/k₀) = ρσ
   - Works for meta-substituted systems
   - Limited for para systems with resonance

2. **Brown-Okamoto (σ⁺):** log(k/k₀) = ρσ⁺
   - For reactions with cationic character
   - EAS, solvolysis, carbocations

3. **Yukawa-Tsuno:** log(k/k₀) = ρ[σ + r(σ⁺ - σ)]
   - Variable resonance demand
   - r = 0: pure σ (like ionization)
   - r = 1: full carbocation

4. **Swain-Lupton:** log(k/k₀) = fF + rR
   - Separates field and resonance
   - Useful for complex systems

### Choosing the Right Parameter

- **Para position with resonance possible:** Use σₚ⁺ (cationic) or σₚ⁻ (anionic)
- **Meta position:** σₘ always appropriate
- **Aliphatic systems:** Use σ* (Taft polar parameter)
- **Steric effects:** Eₛ (Taft) or ν (Charton)
- **Combined steric/electronic:** Charton equation
