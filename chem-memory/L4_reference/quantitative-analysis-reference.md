# Quantitative Analysis Reference

## Titration

### Key equations
- `mol_titrant = M_titrant × V_titrant`
- `mol_analyte = mol_titrant × (coeff_analyte / coeff_titrant)`
- `M_analyte = mol_analyte / V_analyte`
- Shortcut: `M = mmol / mL`

### Common titration types
| Type | Reaction pattern | Indicator |
|------|-----------------|-----------|
| Acid-base | H+ + OH- → H2O | pH indicator |
| Redox | electron transfer | redox indicator |
| Precipitation | ion + ion → solid | color change |

## Gravimetric Analysis

### Key equations
- `mass_analyte = mass_precip × (1/M_precip) × mol_ratio × M_analyte`
- `mass_percent = (mass_analyte / mass_sample) × 100%`

### Requirements
- Precipitate must be pure
- Precipitate must be dry
- Composition must be known

## Combustion Analysis

### Key equations
- `mol_C = mass_CO2 × (1/44.01) × 1`
- `mol_H = mass_H2O × (1/18.02) × 2`
- `empirical formula = simplest C:H ratio`

### Assumptions
- Complete combustion (excess O2)
- All C → CO2
- All H → H2O
