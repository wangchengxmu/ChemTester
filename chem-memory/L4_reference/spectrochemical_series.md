# Spectrochemical Series - Reference Data

## Complete Spectrochemical Series

### Weak to Strong Field Ligands

```
I⁻ < Br⁻ < S²⁻ < SCN⁻ < Cl⁻ < NO₃⁻ < N₃⁻ < F⁻ < OH⁻ < C₂O₄²⁻ < H₂O < NCS⁻ < CH₃CN < py < NH₃ < en < bipy < phen < NO₂⁻ < PPh₃ < CN⁻ ≈ CO
```

### Classification

| Category | Ligands | Δ_o Range | Typical Behavior |
|----------|---------|-----------|------------------|
| **Weak Field (π-donors)** | I⁻, Br⁻, Cl⁻, F⁻, OH⁻, H₂O | Small | High-spin for 3d |
| **Intermediate Field** | NH₃, en, py | Medium | Variable |
| **Strong Field (π-acceptors)** | CN⁻, CO, NO₂⁻ | Large | Low-spin for 3d |

## Ligand Classification by Type

### π-Donor Ligands (weak field)
- Halides: F⁻, Cl⁻, Br⁻, I⁻
- Oxide, hydroxide: O²⁻, OH⁻
- Water: H₂O
- Raise t_2g energy → smaller Δ_o

### π-Acceptor Ligands (strong field)
- Carbonyl: CO
- Cyanide: CN⁻
- Nitrosyl: NO⁺, NO₂⁻
- Phosphines: PPh₃
- Lower t_2g energy → larger Δ_o

### Pure σ-Donors
- Ammonia: NH₃
- Amines: en, bipy, phen
- Intermediate Δ_o values

## Nephelauxetic Effect

### Nephelauxetic Series
```
F⁻ < H₂O < NH₃ < en < ox²⁻ < NCS⁻ < Cl⁻ < CN⁻ < Br⁻ < I⁻
(increasing covalent character → decreasing B)
```
