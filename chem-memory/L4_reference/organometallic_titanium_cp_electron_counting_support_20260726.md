# Titanium Chloride and Cyclopentadienyl Electron-Counting Support

Created: 2026-07-26

Purpose: benchmark-neutral support for organometallic multiple-choice problems
that combine titanium chloride process clues, alkoxide aggregation, Cp ligand
electron counting, and 16e/18e statement checks. This note is not an answer key
and does not name any benchmark problem id.

## Transferable Anchors

- A chloride used historically in ethylene polymerization catalysis is commonly
  TiCl3. It can be formed by reducing TiCl4 with titanium metal, and TiCl4 can
  be made from TiO2 by carbothermal chlorination.
- Titanium mass fractions follow ordinary formula masses. For the sequence
  TiO2, TiCl4, TiCl3, and TiCl2, TiCl4 is the low-Ti-mass-fraction member,
  about 25.2% Ti using Ti = 47.867 and Cl = 35.45.
- Cp is treated as cyclopentadienyl, C5H5-. In ionic electron counting,
  eta5-Cp is a 6e donor and hydride is a 2e X-type donor. Early transition
  metals often form stable electron-deficient complexes; a 16e Ti complex is
  not automatically wrong.
- Mixed-hapticity Cp complexes can have inequivalent ring environments. A
  TiCp4-type 16e description with two strongly bound eta5 Cp rings and two
  weaker Cp contacts can make multiple chemically distinct hydrogen sets.
- Bridging hydride dimers must be counted at each metal center. A Ti dimer with
  Cp/Cp-Cp support and two bridging hydrides can fall short of 18e at each Ti;
  do not mark 18e true solely because hydrides bridge two metals.
- Tetrameric titanium alkoxide structures can have lower skeletal symmetry than
  a high-symmetry D2h assignment. Use the stated oxygen-coordination ratio and
  skeletal connectivity before accepting a point-group statement.

## Validation Use

For a new benchmark item, derive the metal identity and formulas from the
visible clues first, then evaluate each printed statement independently. Select
the option text that exactly matches the resulting true-statement set rather
than relying on option order, problem id, or source answer text.
