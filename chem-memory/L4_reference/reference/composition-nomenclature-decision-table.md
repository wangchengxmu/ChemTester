# L4 Reference: Ch02 Nomenclature Decision Table

## Decision table

1. Is compound ionic?
   - Yes -> metal/polyatomic path
   - No -> molecular prefix path

2. Ionic naming
   - cation name first
   - anion stem + `-ide` (or polyatomic ion name)
   - if cation has variable charge -> append Roman numeral

3. Molecular naming (binary)
   - use prefixes (mono-, di-, tri-, ...)
   - second element ends with `-ide`
