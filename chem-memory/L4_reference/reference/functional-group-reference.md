## Intermolecular Forces by Functional Group

| Functional Group | Dominant IMF | Boiling Point Trend |
|------------------|--------------|---------------------|
| Alkane | London dispersion | Low bp, increases with MW |
| Alkene | London dispersion | Similar to alkanes |
| Alkyne | London dispersion | Similar to alkanes |
| Alcohol | H-bonding | Higher bp than similar MW alkane |
| Carboxylic acid | H-bonding (dimer) | Highest bp among organics |
| Aldehyde/Ketone | Dipole-dipole | Moderate bp |
| Ether | Dipole-dipole | Lower bp than alcohol |
| Amine | H-bonding (1°, 2°) | Moderate-high bp |

## Solubility Guidelines

### Water Solubility Rules
1. Small molecules (< 4-5 carbons) with H-bonding groups: soluble
2. Larger molecules with H-bonding: partially soluble
3. Molecules with only London forces: insoluble
4. Ionic compounds: generally soluble

### "Like Dissolves Like"
| Solute | Solvent | Solubility |
|--------|---------|------------|
| Polar | Polar | High |
| Nonpolar | Nonpolar | High |
| Polar | Nonpolar | Low |
| Nonpolar | Polar | Low |

## Decision Tree: Identifying Principal Functional Group

```
START: Identify all functional groups
    │
    ├─ Carboxylic acid present?
    │   └─ YES → Principal group = carboxylic acid
    │
    ├─ Ester or amide present?
    │   └─ YES → Principal group (ester > amide > nitrile)
    │
    ├─ Aldehyde or ketone present?
    │   └─ YES → Principal group = aldehyde or ketone
    │
    ├─ Alcohol or amine present?
    │   └─ YES → Principal group = alcohol or amine
    │
    ├─ Multiple bond present?
    │   └─ YES → Principal group = alkene or alkyne
    │
    └─ Default: alkane
```
