| Element | Reaction Vigor | Products | Notes |
|---------|---------------|----------|-------|
| Li | Moderate | LiOH + H₂ | Slower than Na (higher MP) |

| K | Explosive | KOH + H₂ | Ignites H₂ |
| Rb | Explosive | RbOH + H₂ | Often explosive |
| Cs | Explosive | CsOH + H₂ | Highly explosive |
| Be | None | - | Oxide layer protects |
| Mg | Slow | Mg(OH)₂ + H₂ | Faster with steam |
| Ca | Moderate | Ca(OH)₂ + H₂ | Warm solution |
| Sr | Moderate | Sr(OH)₂ + H₂ | Warm solution |

## Key Reactions

### With Water (Group 1)
```
2M + 2H₂O → 2MOH + H₂
```

### With Water (Group 2)
```
M + 2H₂O → M(OH)₂ + H₂
```

### With Oxygen
```
4Li + O₂ → 2Li₂O
2Na + O₂ → Na₂O₂
K + O₂ → KO₂
```

### With Nitrogen (Li only in Group 1)
```
6Li + N₂ → 2Li₃N
```

### With Halogens
```
2M + X₂ → 2MX (Group 1)
M + X₂ → MX₂ (Group 2)
```

| Li-Mg | Both form nitrides, organometallics |

## Group Comparisons

| Property | Group 1 | Group 2 |
|----------|---------|---------|
| Common charge | +1 | +2 |
| Reactivity with N₂ | Li only | All except Be |
| Hydride direct | All | All except Be |
| Oxide character | All basic | BeO amphoteric |
| Organometallic stability | Li most covalent | Be, Mg most covalent |
| Complex formation | Weak | Stronger |
