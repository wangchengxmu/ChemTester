## Hydrogen Bonding Criteria

### H-Bond Donors
- O-H (alcohols, water, carboxylic acids)
- N-H (amines, amides)
- F-H (hydrogen fluoride)

### H-Bond Acceptors
- O (carbonyl, ether, alcohol oxygen)
- N (amines, amides)
- F (fluorine with lone pairs)

## Decision Tree for Predicting Relative BP

```
1. Check for hydrogen bonding capability
   ├── Both molecules H-bond → Compare H-bond count
   │   └── More H-bonds → Higher BP
   ├── One H-bonds, other doesn't → H-bonding molecule has higher BP
   └── Neither H-bonds → Go to step 2

2. Check polarity
   ├── Both polar → Compare dipole moments
   │   └── Larger dipole → Higher BP (usually)
   ├── One polar, one nonpolar → Polar has higher BP (usually)
   └── Both nonpolar → Go to step 3

3. Compare molecular mass and surface area
   ├── Higher MW → Higher BP
   └── Same MW: More linear → Higher BP (more surface area)
```

## Key Formulas

### Dipole-Dipole Energy
$$E_{dip} \propto -\frac{\mu_1 \mu_2}{r^6}$$

### London Dispersion Energy
$$E_{London} \propto -\frac{\alpha_1 \alpha_2}{r^6}$$

### Polarizability-Mass Correlation
$$\alpha \propto n \times V_{atom}$$
where n = number of electrons, V = atomic volume

## Common Mistakes

1. **Confusing polarity with H-bonding**: All H-bonding molecules are polar, but not all polar molecules can H-bond.

2. **Ignoring London forces for polar molecules**: London forces exist for ALL molecules. For large molecules, they can dominate even if polar.

3. **Forgetting surface area effects**: For isomers with same MW, branching reduces surface area and weakens London forces.

4. **Assuming all H-bonds are equal**: N-H···O is weaker than O-H···O.
