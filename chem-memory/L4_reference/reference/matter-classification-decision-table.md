# L4 Reference: Matter Classification and Change Decision Table

## Classification cues
- Fixed composition + pure substance -> element/compound path
- Variable composition -> mixture path
- Visible multiple phases -> likely heterogeneous mixture

## Change typing cues
- New substance indicators (gas evolution, precipitate, persistent color/reactivity shift) -> chemical change
- State/form change only (melting, boiling, dissolving without reaction evidence) -> physical change
