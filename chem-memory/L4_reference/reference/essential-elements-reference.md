# Essential Elements for Life

[Source: Averill, Ch01]

## Overview

Of the approximately 115 known elements, only **19 elements are absolutely required** in the human diet. These elements are called **essential elements**.

## Location in Periodic Table

Essential elements are restricted to the **first four rows** of the periodic table, with only two or three exceptions:
- Molybdenum (Mo) - Row 5
- Iodine (I) - Row 5
- Tin (Sn) - Row 5 (possibly essential)

## Classification by Abundance

### Major Elements (96% of body mass)
| Element | Symbol | Primary Function |
|---------|--------|------------------|
| Oxygen | O | Water, respiration |
| Carbon | C | Organic molecules |
| Hydrogen | H | Water, organic molecules |
| Nitrogen | N | Proteins, nucleic acids |

### Macrominerals
| Element | Symbol | Primary Function |
|---------|--------|------------------|
| Calcium | Ca | Bones, signaling |
| Phosphorus | P | ATP, nucleic acids, bones |
| Potassium | K | Nerve signaling |
| Sulfur | S | Proteins |
| Sodium | Na | Fluid balance, nerves |
| Chlorine | Cl | Electrolyte balance |
| Magnesium | Mg | Enzymes, ATP |

### Trace Elements
| Element | Symbol | Primary Function |
|---------|--------|------------------|
| Iron | Fe | Hemoglobin, enzymes |
| Zinc | Zn | Enzymes |
| Copper | Cu | Enzymes |
| Manganese | Mn | Enzymes |
| Iodine | I | Thyroid hormones |
| Selenium | Se | Antioxidant enzymes |
| Molybdenum | Mo | Enzymes |
| Fluorine | F | Tooth enamel |
| Chromium | Cr | Glucose metabolism |
| Cobalt | Co | Vitamin B12 |

## Elements Essential for Specific Organisms

Some elements are essential for certain organisms but not humans:
- **Boron (B)** - Plants
- **Silicon (Si)** - Some plants and animals
- **Vanadium (V)** - Some organisms
- **Nickel (Ni)** - Some microorganisms

## Dietary Considerations

### Deficiency Diseases
- Iron deficiency → Anemia
- Iodine deficiency → Goiter
- Calcium deficiency → Osteoporosis
- Zinc deficiency → Growth retardation

### Toxicity Thresholds
All essential elements have a toxicity range. The difference between required amount and toxic amount varies:
- Wide margin: Na, K, Cl
- Narrow margin: Se, Cu, F
