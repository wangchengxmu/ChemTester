# L4 Reference: Ch01 Formulas and Unit Conversions

## Core formulas
- Density: `rho = m / V`
- Rearranged forms: `m = rho V`, `V = m / rho`

## Common unit conversions
- 1 L = 1000 mL
- 1 kg = 1000 g
- 1 m = 100 cm
- 1 cm^3 = 1 mL
