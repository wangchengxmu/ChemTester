## Inert-Pair Effect

Elements preferring OS = Group - 2:
- Tl: Prefers +1 over +3
- Pb: Prefers +2 over +4
- Bi: Prefers +3 over +5
- Sn: +2 increasingly stable
- Sb: +3 increasingly stable

## Catenation Ability

### Group 14
```
C >> Si > Ge ≈ Sn > Pb
```

### Group 15
```
N << P > As > Sb > Bi
```

### Group 16
```
O << S > Se > Te
```

## Halogen Oxidizing Power

```
F₂ > Cl₂ > Br₂ > I₂
```

Standard reduction potentials:
- F₂: +2.87 V
- Cl₂: +1.36 V
- Br₂: +1.09 V
- I₂: +0.54 V

## Key Trends

### Metallic Character
Increases down and to the left

### Ionization Energy
Decreases down, increases right

### Electronegativity
Decreases down, increases right
F > O > Cl > N > Br > I > S > C

### Oxide Acidity
Higher oxidation state = more acidic
More electronegative element = more acidic
