## IUPAC Naming Rules

### Step-by-Step
1. **Find the longest continuous carbon chain**
   - This becomes the parent name
   - May not be straight in the drawing

2. **Number the chain**
   - Start from end nearest first substituent
   - Give lowest possible numbers to substituents

3. **Identify substituents**
   - Use alkyl group names
   - Note position numbers

4. **Arrange substituents alphabetically**
   - Ignore di-, tri-, tetra- prefixes
   - Use commas between numbers
   - Use hyphens between numbers and letters

### Naming Format
```
[locant]-[prefix][substituent]-[parent]

Example: 2,3-dimethylbutane
         ↓   ↓    ↓      ↓
       locants  prefix  parent
```

### Cycloalkane Naming
- Prefix "cyclo-" before alkane name
- Number substituents for lowest locants
- For multiple substituents, number alphabetically

### Examples
| Structure | Name |
|-----------|------|

## Physical Properties Summary

### Boiling Point Trends
1. Increases with molecular weight
2. Decreases with branching
3. Straight chains have highest BP

### Melting Point Trends
1. Generally increases with molecular weight
2. Symmetrical molecules have higher MP
3. Even-numbered alkanes have higher MP than odd

### Density
- All alkanes less dense than water (d < 1.0 g/mL)
- Increase slightly with molecular weight

### Solubility
- Insoluble in water (hydrophobic)
- Soluble in nonpolar organic solvents
- "Like dissolves like"

## Common Naming Errors to Avoid

| Error | Incorrect | Correct |
|-------|-----------|---------|
| Wrong parent | 1-methylpropane | Butane (or 2-methylpropane) |
| Wrong numbering | 3-methylbutane | 2-methylbutane |
| Missing prefix | dimethylpentane | 2,2-dimethylpentane |
| Wrong order | methyl-ethyl-... | ethyl-methyl-... |

## Quick Reference: Naming Flowchart

```
1. Count all carbons
2. Find longest chain → parent name
3. Identify substituents
4. Number chain (lowest numbers)
5. Write name:
   - Locants (comma-separated)
   - Hyphen
   - Substituent names (alphabetical)
   - Parent name
```
