## 4. Electrochemical Constants

### Faraday's Constant
```
F = 96,487 C/mol e⁻ = 96,487 A·s/mol e⁻
F = 23,061 cal/(V·mol e⁻)
F = 96.487 kJ/(V·mol e⁻)
```

### Gas Constant
```
R = 8.314 J/(mol·K) = 0.08206 L·atm/(mol·K)
```

| Analyte | Reaction | Electrode | Potential Range (V vs SCE) |
|---------|----------|-----------|---------------------------|
| Cu²⁺ | Cu²⁺ + 2e⁻ → Cu | Pt or Hg | -0.3 to -0.5 |
| Pb²⁺ | Pb²⁺ + 2e⁻ → Pb | Pt or Hg | -0.6 to -0.8 |
| Cd²⁺ | Cd²⁺ + 2e⁻ → Cd | Pt or Hg | -0.7 to -1.0 |

## 10. Common Electrochemical Cell Configurations

### Standard Cell Components

| Component | Common Materials | Purpose |
|-----------|------------------|---------|
| Working electrode | Hg, Pt, Au, C (glassy, paste) | Site of redox reaction |
| Reference electrode | SCE, Ag/AgCl, SHE | Fixed potential reference |
| Counter electrode | Pt wire, graphite rod | Completes circuit |
| Supporting electrolyte | KCl, KNO₃, HClO₄, buffer | Carries current, eliminates migration |
| Cell material | Glass, PTFE, quartz | Inert container |

### Typical Concentrations

| Component | Concentration Range |
|-----------|-------------------|
| Analyte | 10⁻³ to 10⁻⁹ M |
| Supporting electrolyte | 0.1 to 1.0 M (100-1000× excess) |
| Buffer | 0.01 to 0.5 M |
