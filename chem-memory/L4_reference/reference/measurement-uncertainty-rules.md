# L4 Reference: Ch01 Uncertainty and Significant-Figure Rules

## Operational rules

1. Multiplication/Division:
   - result sig figs = minimum sig figs among inputs.

2. Addition/Subtraction:
   - result decimal places = minimum decimal places among inputs.

3. Uncertainty format:
   - `value ± uncertainty`
   - align decimal precision between value and uncertainty.

## Caution
- Keep full precision in intermediate computation; round at final reporting step.
