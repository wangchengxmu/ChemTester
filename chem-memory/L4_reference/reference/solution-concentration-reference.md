## Core definitions
- Molarity: `C = n / V` (V in liters)
- Dilution (no reaction; solute amount conserved): `C1V1 = C2V2`
- `%m/m = (m_solute / m_solution) × 100%`
- `%v/v = (V_solute / V_solution) × 100%`
- `%m/v = g solute per 100 mL solution`
- `ppm = (m_solute / m_solution) × 10^6`
- `ppb = (m_solute / m_solution) × 10^9`

## Conversion matrix (minimal)
- mL ↔ L: `1000 mL = 1 L`
- ppm (aqueous, ρ≈1.00 g/mL) ≈ mg/L
- ppb (aqueous, ρ≈1.00 g/mL) ≈ µg/L

## Density requirement matrix
- molarity from moles & liters: density **not required**
- `%m/m` and ppm/ppb by mass ratio: density **not required**
- mass↔volume conversions across domains (%m/m to %v/v, mg/L from non-aqueous ppm): density **required**

## Applicability constraints
- Use `C1V1=C2V2` only when no chemical reaction, decomposition, or association changes solute amount.
- Report assumptions explicitly (especially ρ≈1.00 g/mL shortcuts).
