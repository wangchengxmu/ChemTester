# Positional substituent effects on aromatic carbonyl IR

**Retrieve with:** aromatic aldehyde IR substituent position, nitro aryl carbonyl frequency regioisomers, ortho meta para carbonyl probe

**Use when:** Comparing carbonyl stretching frequencies among regioisomeric aromatic aldehydes or ketones bearing the same ring substituent.

## Procedure

1. Parse each structure first and label the substituent as ortho, meta, or para relative to the carbonyl-bearing ring carbon.
2. Because the compared carbonyls have essentially the same reduced mass, rank changes in their effective force constant rather than applying a molecular-mass heuristic.
3. Consider field/inductive, resonance-transmission, and ortho-specific conformational or through-space effects separately; no single electron-withdrawal or steric slogan determines every ordering.
4. An exact positional-isomer order requires identified measured bands or a traceable source for the same compounds, solvent or phase, and assignment; generic topic notes do not establish an empirical sequence.
5. Establish the compound sequence before mapping it to the requested answer format.

## Guards

- Never rank an ortho isomer from steric deconjugation alone.
- Without matched empirical support, describe competing effects and leave an exact sequence unresolved rather than asserting a memorized class order.
- Explicit solvent, phase, conformer, or measured-band data override a generic class trend.
- Determine the chemistry ordering before inspecting option labels.
