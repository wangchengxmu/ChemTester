# Alternative Reagents

## Source
[Key Elements of Green Chemistry (Lucia), Chapter 5](https://chem.libretexts.org/Bookshelves/Environmental_Chemistry/Key_Elements_of_Green_Chemistry_(Lucia)/05%3A_Alternative_Reagants)
Author: Lucian Lucia, North Carolina State University

## Key Concepts

### Green Reagent Selection
- Reagents should be: less toxic, renewable, atom-efficient, selective
- Avoid stoichiometric reagents that generate stoichiometric waste
- Prefer catalytic processes over stoichiometric ones

### Specific Reagent Replacements
| Hazardous Reagent | Green Alternative | Application |
|---|---|---|
| Cr(VI) oxidants | H₂O₂, NaClO₂, TEMPO | Oxidations |
| Phosphorus oxychloride (POCl₃) | Solid acid catalysts | Friedel-Crafts |
| Benzene (carcinogen) | Cyclohexane, bio-based aromatics | Solvent/feedstock |
| Formaldehyde | Paraformaldehyde | Crosslinking |
| Chlorine gas | Electrochemical chlorination | Chlorination |
| Thionyl chloride (SOCl₂) | Oxalyl chloride, catalytic methods | Chlorination |

### Solid-Supported Reagents
- Packed-bed reactors: fixed substrate provides reagents (protons, ions)
- Advantages: easy separation, reusability, reduced waste
- Ion-exchange resins as acid/base catalysts
- Polymer-supported reagents for peptide synthesis

### Renewable Reagents
- Bio-based feedstocks: sugars, lignin, vegetable oils
- CO₂ as a C₁ building block (carboxylation, polymerization)
- H₂ from renewable sources for hydrogenations
- Enzymatic/biocatalytic reagents

### Reagent Design Principles
- Minimize auxiliary substances (Principle 5)
- Maximize atom economy (Principle 2)
- Use catalytic rather than stoichiometric reagents (Principle 9)

## Formulas
- Atom Economy for reagent comparison: AE = (MW_product / Σ MW_reagents) × 100%
