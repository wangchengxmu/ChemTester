# Safety Chemistry: Energetic Materials And Oxidizer Classification

Use this note when a chemistry or safety question asks which listed energetic
materials are oxidizers, fuels, high explosives, or propellant ingredients.

## Oxidizer Pattern

- Oxidizers are substances that can supply oxygen or other oxidizing equivalents
  to support combustion or rapid redox reactions.
- Perchlorate, nitrate, chlorate, and dinitramide salts are common oxidizer
  families in propellants and energetic formulations.
- Oxygen-rich ammonium salts can function as oxidizers when their anions provide
  oxidizing oxygen or nitro/nitramide equivalents.

## Common Classifications

- Ammonium perchlorate is a classic solid rocket propellant oxidizer.
- Ammonium nitrate is a common oxidizer in fertilizers and explosive mixtures.
- Ammonium dinitramide is an energetic oxidizer used or investigated for
  propellant applications.
- Nitroaromatic high explosives such as TNT are energetic fuels/explosives, but
  they are not normally classified as oxidizers.
- Nitrogen-rich explosive salts can be energetic without being the oxidizer in a
  formulation; check whether the compound is oxygen-rich enough and used as an
  oxidizing component.

## Multi-Select Procedure

1. Classify each visible chemical independently; do not stop after the first
   familiar oxidizer.
2. Select all oxidizer-family entries, especially perchlorates, nitrates,
   chlorates, and dinitramide salts.
3. Exclude entries whose main role is a fuel or high explosive unless the prompt
   or established classification identifies them as oxidizers.
4. Return only the required option-letter set when the problem asks for letters.

## Reducing Agents With Oxidizing Acids

Reducing agents and oxidizing acids can be incompatible, but an exact set of
hazard labels is an empirical, source-specific record. Identify the substances
or reactive-group pair, source version, concentrations and stated conditions.
For a table-reading question, report only what that exact record supports and
distinguish it from a general chemical hazard assessment. A missing label is
not evidence that a hazard is absent. Without the relevant record, do not
invent a category list or use visible options to manufacture one. This note
does not authorize mixing or replace an SDS and site compatibility procedure.

## Guards

- "Energetic" and "explosive" are not synonyms for "oxidizer".
- Do not infer an answer from option position or from a benchmark label.
- If two ammonium energetic salts are listed, classify them by their anion, not
  merely by the shared cation.
