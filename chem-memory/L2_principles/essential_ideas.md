## Matter Classification

| Classification | Definition | Examples |
|---|---|---|
| Element | Single type of atom | Au, O₂, Fe |
| Compound | Two+ elements chemically bonded in fixed ratio | H₂O, NaCl, CO₂ |
| Mixture | Two+ substances physically combined | Air, salt water |
| Homogeneous mixture | Uniform composition (solution) | Brass, tea |
| Heterogeneous mixture | Non-uniform composition | Granite, salad |
| Pure substance | Element or compound with fixed composition | H₂, NaCl |

Physical vs chemical change:
- Physical: change in state/shape without new substances (melting ice)
- Chemical: new substances formed (burning wood)

## SI Base Units

| Quantity | Unit | Symbol |
|---|---|---|
| Length | meter | m |
| Mass | kilogram | kg |
| Time | second | s |
| Temperature | kelvin | K |
| Amount | mole | mol |
| Electric current | ampere | A |
| Luminous intensity | candela | cd |

Common derived: L (volume, 1 L = 10⁻³ m³), J (energy, 1 J = 1 kg·m²/s²), Pa (pressure, 1 Pa = 1 N/m²).

## SI Prefixes

Tera (10¹²), Giga (10⁹), Mega (10⁶), kilo (10³), deci (10⁻¹), centi (10⁻²), milli (10⁻³), micro (10⁻⁶), nano (10⁻⁹), pico (10⁻¹²).

## Uncertainty and Significant Figures

Rules for significant figures:
1. Non-zero digits always significant
2. Leading zeros never significant
3. Captive zeros (between non-zero) always significant
4. Trailing zeros significant only if decimal present
5. In multiplication/division: result has fewest sig figs of inputs
6. In addition/subtraction: result has fewest decimal places of inputs

Exact numbers (counting, defined conversions) have unlimited sig figs.

## Dimensional Analysis

**Principle:** Multiply by conversion factors equal to 1 (e.g., 100 cm / 1 m) to change units.

Steps:
1. Write given quantity with its unit
2. Multiply by conversion factor(s) so unwanted units cancel
3. Compute numerical result
4. Apply sig fig rules

## Density

ρ = m / V

Units: g/cm³, g/mL, kg/m³. Water density ≈ 1.00 g/mL at 4°C.

## Temperature Conversions

- °C to K: T_K = T_C + 273.15
- °F to °C: T_C = (T_F - 32) × 5/9
- °C to °F: T_F = T_C × 9/5 + 32
