## Key Concepts

**Natural Products:** Aspirin (willow bark → salicin → salicylic acid → acetylsalicylic acid, Bayer 1899), morphine/codeine (poppy, 1804/1832), penicillin (Fleming 1928, Nobel 1945).

**Drug Discovery Pipeline:**
1. Target Selection: disease/target, validation (e.g., BCR-ABL in CML → imatinib)
2. Hit Identification & Hit-to-Lead: assays (NMR, fluorescence, imaging), hit compounds → lead compound (activity + synthetic feasibility + target reachability)
3. Lead Optimization: preserve potency, improve PK/bioavailability (e.g., sorafenib: IC50 17µM → 6nM)
4. Preclinical/Clinical: Phase I (safety, healthy), II (disease cohort), III (large population). ~7% success rate, 15-20 years, $1-2B.

**Rational Drug Design:** Ehrlich's magic bullet → side-chain theory → arsphenamine/neosalvarsan.

**Target Understanding:** ~20,000 human genes, ~15% druggable. 2/3 of drugs target kinases or GPCRs.

**Kinase Drug Binding (6 types):**
- Type I: orthosteric ATP site (crizotinib, dasatinib)
- Type II: DFG-out inactive (sorafenib)
- Type III: deep hydrophobic pocket (kinase-specific)
- Type IV: allosteric site
- Type V: bivalent (both lobes)
- Type VI: covalent (cysteine)

**Resistance:** Gatekeeper mutations (T315I in BCR-ABL → ponatinib with ethynyl group; T790M in EGFR).
