# Coordination Chemistry - Structure and Isomers

## Overview

Coordination compounds consist of a central metal ion bound to one or more ligands. They are fundamental to catalysis, biochemistry, and materials science.

**Source:** CHM 320 Chapter 5 (LibreTexts)

---

## Basic Concepts

### Definitions

| Term | Definition |
|------|------------|
| **Coordination compound** | Metal ion with attached ligands |
| **Coordination sphere** | Metal + directly bound ligands (in square brackets) |
| **Coordination number** | Number of ligand donor atoms bound to metal |
| **Ligand** | Lewis base that donates electron pair to metal |
| **Complex ion** | Charged coordination compound |

### The Coordinate Covalent Bond
- Both electrons in the M-L bond come from the ligand
- Ligand is the donor (Lewis base)
- Metal is the acceptor (Lewis acid)

## Naming Coordination Compounds

### IUPAC Rules

1. **Cation before anion** (like simple salts)
2. **Ligands named first** (alphabetically), then metal
3. **Ligand names:**
   - Anionic: -ide → -o (chloride → chloro)
   - Neutral: use original name (ammonia, water → aqua)
4. **Prefixes indicate number:** di-, tri-, tetra-, penta-, hexa-
5. **Metal name:**
   - Neutral/positive: element name
   - Negative: -ate ending (ferrate, cobaltate, cuprate)
6. **Oxidation state** in Roman numerals after metal name

### Examples

| Formula | IUPAC Name |
|---------|------------|
| [Co(NH₃)₆]Cl₃ | hexaamminecobalt(III) chloride |
| K₃[Fe(CN)₆] | potassium hexacyanoferrate(III) |
| [PtCl₂(NH₃)₂] | diamminedichloroplatinum(II) |
| [Co(en)₃]Cl₃ | tris(ethylenediamine)cobalt(III) chloride |
| Na[Co(CO)₄] | sodium tetracarbonylcobaltate(-I) |

### Common Ligand Names

## Ligand Types

### Monodentate Ligands
Single donor atom:
- **Anionic:** Cl⁻, Br⁻, I⁻, OH⁻, CN⁻, SCN⁻
- **Neutral:** NH₃, H₂O, CO, PR₃

### Bidentate Ligands
Two donor atoms:
- **ethylenediamine (en):** NH₂CH₂CH₂NH₂ (N,N-donor)
- **oxalate (ox):** C₂O₄²⁻ (O,O-donor)
- **acetylacetonate (acac):** (O,O-donor)
- **bipyridine (bipy):** (N,N-donor)

### Polydentate Ligands (Chelates)
Multiple donor atoms:
- **EDTA:** Hexadentate (4 N, 2 O donors)
- **diethylenetriamine (dien):** Tridentate (3 N donors)

### Chelate Effect
Chelating ligands form more stable complexes than equivalent monodentate ligands:
- Entropy-driven (more particles released)
- Kinetic stability from ring formation

## Isomerism in Coordination Compounds

### Structural Isomers
Different connectivity between atoms

#### 1. Ionization Isomers
Different counterions exchanged with ligands:
- [Co(NH₃)₅Br]SO₄ vs [Co(NH₃)₅SO₄]Br

#### 2. Hydrate Isomers
Different water placement:
- [Cr(H₂O)₆]Cl₃ vs [Cr(H₂O)₅Cl]Cl₂·H₂O

#### 3. Coordination Isomers
Different metal-ligand combinations in multi-metal complexes:
- [Co(NH₃)₆][Cr(CN)₆] vs [Cr(NH₃)₆][Co(CN)₆]

#### 4. Linkage Isomers
Different donor atom from ambidentate ligand:
- [Co(NH₃)₅NO₂]²⁺ (nitro, N-bound)
- [Co(NH₃)₅ONO]²⁺ (nitrito, O-bound)

### Stereoisomers
Same connectivity, different spatial arrangement

#### 1. Geometric Isomers (cis-trans)

**Square Planar [MA₂B₂]:**
```
cis-MA₂B₂:     trans-MA₂B₂:
  A              A
  |              |
M---A          M---B
  |              |
  B              B
```

**Octahedral [MA₄B₂]:**
- cis: adjacent positions
- trans: opposite positions

**Octahedral [MA₃B₃]:**
- fac (facial): 3 identical ligands on one face
- mer (meridional): 3 identical ligands around meridian

#### 2. Optical Isomers (Enantiomers)

Non-superimposable mirror images:
- **Chiral complexes** have no plane of symmetry
- Common for octahedral complexes with bidentate ligands
- Example: [Co(en)₃]³⁺ has Δ and Λ enantiomers

**Notation:**
- Δ (delta): right-handed helix
- Λ (lambda): left-handed helix

## Identifying Isomer Types

### Decision Tree
```
1. Same molecular formula?
   → No: Not isomers
   → Yes: Continue

2. Same connectivity?
   → No: Structural isomers
        - Counter ions exchanged? → Ionization isomers
        - Water moved? → Hydrate isomers
        - Multiple metals? → Coordination isomers
        - Ambidentate ligand? → Linkage isomers

   → Yes: Stereoisomers
        - Chiral? → Optical isomers
        - Different positions? → Geometric isomers (cis/trans, fac/mer)
```

## Stability Constants

### Formation Constant
```
M + nL ⇌ MLn
K_f = [MLn] / ([M][L]^n)
```

### Stepwise Formation
```
M + L ⇌ ML        K₁ = [ML]/([M][L])
ML + L ⇌ ML₂      K₂ = [ML₂]/([ML][L])
...
```

### Overall Formation
```
M + nL ⇌ MLn      β_n = K₁ × K₂ × ... × K_n
```

### Factors Affecting Stability
1. **Chelate effect:** Chelates more stable than monodentates
2. **Macrocyclic effect:** Large rings enhance stability
3. **LFSE:** Higher LFSE → more stable
4. **Metal ion charge/size:** Higher charge, smaller size → stronger binding
5. **Hard-soft matching:** Hard metals prefer hard ligands
