## Context

The p-block elements comprise Groups 13-18, where valence electrons occupy p orbitals. This block shows the greatest diversity in properties: from nonmetals (N, O, halogens) to metalloids (Si, Ge, As, Sb) to metals (Al, Ga, In, Tl, Pb, Bi). Understanding p-block chemistry is essential for materials science, biology, and industrial applications.

## Core Concepts

### 1. General Trends Across the p-Block

| Property | Trend Across p-Block |
|----------|---------------------|
| Metallic character | Increases down and left |
| Ionization energy | Decreases down, increases right |
| Electronegativity | Decreases down, increases right |
| Oxidation states | Multiple states common; highest state less stable down group |

**Inert-Pair Effect:** Heavier p-block elements prefer lower oxidation states (group oxidation state - 2) due to reluctance of ns² electrons to participate in bonding.

### 2. Group 13: Boron Family (B, Al, Ga, In, Tl)

**Electronic configuration:** ns²np¹

| Property | Trend |
|----------|-------|
| Character | B: nonmetal; Al-Tl: metals |
| Common oxidation states | +3; Tl prefers +1 (inert-pair) |
| Oxide nature | B₂O₃: acidic; Al₂O₃: amphoteric; others: basic |

**Key features:**
- Boron forms covalent compounds (electron deficiency → multicenter bonding)
- Aluminum: most abundant metal in Earth's crust
- Thallium: toxic, +1 oxidation state most stable

### 3. Group 14: Carbon Family (C, Si, Ge, Sn, Pb)

**Electronic configuration:** ns²np²

| Element | Character | Key Features |
|---------|-----------|--------------|
| C | Nonmetal | Catenation, multiple bonds, organic chemistry |
| Si | Metalloid | Semiconductors, silicates |
| Ge | Metalloid | Semiconductors |
| Sn | Metal | Two allotropes (white, gray) |
| Pb | Metal | Toxic, +2 oxidation state preferred |

**Catenation ability:** C >> Si > Ge ≈ Sn > Pb

**Oxidation states:** +4 and +2; +2 becomes more stable down group (inert-pair effect)

### 4. Group 15: Pnicogens (N, P, As, Sb, Bi)

**Electronic configuration:** ns²np³

| Element | Character | Common Oxidation States |
|---------|-----------|------------------------|
| N | Nonmetal | -3 to +5 (9 oxidation states!) |
| P | Nonmetal | +5, +3, -3 |
| As | Metalloid | +5, +3 |
| Sb | Metalloid | +5, +3 |
| Bi | Metal | +3 (inert-pair effect) |

**Nitrogen special features:**
- Forms N≡N (extremely strong: 942 kJ/mol)
- Cannot expand octet (no d orbitals)
- Multiple bonds with second-period elements
- Does not form long chains (lone pair repulsions)

**Phosphorus and heavier:**
- Can use d orbitals for dsp³, d²sp³ hybridization
- Coordination numbers of 5, 6 possible
- Form π bonds with O, N (strong P=O bonds)
- Catenation possible (P₄, polyphosphates)

**Oxides:**
- N: NO, N₂O, NO₂ (all thermodynamically unstable)
- P: P₄O₆, P₄O₁₀ (stable, acidic)
- As: As₄O₆ (acidic)
- Sb: Sb₄O₆ (amphoteric)
- Bi: Bi₂O₃ (basic)

### 5. Group 16: Chalcogens (O, S, Se, Te, Po)

**Electronic configuration:** ns²np⁴

| Element | Character | Key Features |
|---------|-----------|--------------|
| O | Nonmetal | O₂, O₃ (ozone), strong oxidizer |
| S | Nonmetal | S₈ rings, many allotropes |
| Se | Metalloid | Photovoltaic properties |
| Te | Metalloid | Semiconductor |
| Po | Metal | Radioactive |

**Trends:**
- Electronegativity decreases down group
- Tendency for -2 oxidation state decreases
- Catenation ability decreases: S > Se > Te
- Multiple bond ability: O >> S > Se > Te

**Hydrogen compounds (H₂E):**
- H₂O: Liquid, H-bonding
- H₂S, H₂Se, H₂Te: Gases, toxic, weak acids

### 6. Group 17: Halogens (F, Cl, Br, I, At)

**Electronic configuration:** ns²np⁵

| Property | Trend |
|----------|-------|
| State at RT | F₂, Cl₂: gases; Br₂: liquid; I₂: solid |
| Reactivity | Decreases down group |
| Oxidation states | F: -1 only; others: -1, +1, +3, +5, +7 |
| Oxidizing power | Decreases down group |

**Fluorine anomalies:**
- Most electronegative element
- Electron affinity < Cl (small size, e⁻ repulsion)
- Weak F-F bond (lone pair repulsion)
- Forms compounds with every element except He, Ne, Ar

**Reactions:**
- With metals: MXₙ (ionic)
- With H₂: HX (hydrogen halides)
- With H₂O: H⁺ + X⁻ + HOX (disproportionation, except F₂)
- Interhalogens: XX'ₙ (heavier halogen central)

**Oxoacids:**
- HOX (hypohalous), HXO₂ (halous), HXO₃ (halic), HXO₄ (perhalic)
- Acid strength increases with oxidation state
- Acid strength and oxidizing power decrease down group

### 7. Group 18: Noble Gases (He, Ne, Ar, Kr, Xe, Rn)

**Electronic configuration:** ns²np⁶ (except He: 1s²)

| Element | Reactivity |
|---------|-----------|
| He, Ne | No known compounds |
| Ar | Very few compounds (HArF at low T) |
| Kr | KrF₂ known |
| Xe | Many compounds: XeF₂, XeF₄, XeF₆, XeO₃, XeO₄ |
| Rn | Radioactive, compounds presumed similar to Xe |

**Xenon compounds:**
- XeF₂: linear (sp³d hybridization)
- XeF₄: square planar (sp³d²)
- XeF₆: distorted octahedral
- All are strong fluorinating agents

**Formation requires:**
- Potent oxidant (F₂, PtF₆)
- High electronegativity difference
- Favorable lattice energy (for salts)

## Decision Flow

### Predicting Oxidation State Stability

1. **Identify the element's position in group**
   - Lighter: Higher oxidation states more stable
   - Heavier: Lower oxidation states preferred (inert-pair)

2. **Consider the bonding partner**
   - F, O: Stabilize high oxidation states
   - Less electronegative: Lower states

3. **Apply inert-pair rule for heavy elements**
   - Tl(+1), Pb(+2), Bi(+3) most stable
   - Sb, Sn: +3 and +4 both common

### Predicting Metal vs Nonmetal Behavior

1. **Locate element on p-block**
   - Upper right: Nonmetallic
   - Lower left: Metallic
   - Diagonal: Metalloids

2. **Apply diagonal relationships**
   - B-Si, Al-Ge similarities
   - Li-Mg, Be-Al (s-block parallels)

## Quantitative Relationships

**Bond strength trend (X-X single bonds):**
```
N-N: 167 kJ/mol (weak, lone pair repulsion)
P-P: 201 kJ/mol
As-As: 146 kJ/mol
Sb-Sb: 121 kJ/mol
```

**Oxide acidity trend:**
```
Higher oxidation state → More acidic oxide
More electronegative element → More acidic oxide
```

**Catenation stability:**
```
C >> Si > Ge ≈ Sn > Pb (Group 14)
N << P > As > Sb > Bi (Group 15)
O << S > Se > Te (Group 16)
```

## Edge Cases

- **Boron:** Electron-deficient, forms cluster compounds (B₂H₆, B₁₂H₁₂²⁻)
- **Carbon:** Infinite catenation, basis of organic chemistry
- **Nitrogen:** Unusually weak N-N single bonds, strong N≡N triple
- **Oxygen:** Only element with multiple bonds to itself in elemental form
- **Fluorine:** Highest electronegativity, but lower electron affinity than Cl
- **Xenon:** Noble gas that forms many compounds

p-Block elements: oxidation states, halogen properties, inert pair effect, allotropes.

### Available functions:
- `group_oxidation_states(group)` → List[int] — Common oxidation states for p-block group
- `halogen_property(element, property_name)` → float — Get halogen property (electronegativity, EA, bond energy, etc.)
- `noble_gas_property(element)` → dict — Noble gas properties including IE and known compounds
- `inert_pair_effect(group, period)` → str — Predict inert pair effect strength and stability of +2/+4 oxidation states
- `halogen_displacement(halogen1, halogen2)` → str — Predict if X₁ can displace X₂ from halide (more electronegative wins)
- `allotrope_exists(element)` → List[str] — List known allotropes for element
- `p_block_oxide_type(element)` → str — Classify oxide as acidic/basic/amphoteric
- `group_14_element(element)` → dict — Properties and trends for Group 14 elements

### Common errors:
- ❌ Forgetting that inert pair effect increases down a group (Tl⁺, Pb²⁺, Bi³⁺)
- ❌ Assuming all p-block oxides are acidic (many are amphoteric or basic)
