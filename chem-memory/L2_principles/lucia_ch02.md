# Life-Cycle Analysis (LCA)

## Source
[Key Elements of Green Chemistry (Lucia), Chapter 2](https://chem.libretexts.org/Bookshelves/Environmental_Chemistry/Key_Elements_of_Green_Chemistry_(Lucia)/02%3A_Life-Cycle_Analysis)
Author: Lucian Lucia, North Carolina State University

## Key Concepts

### LCA Framework (ISO 14040/14044)
1. **Goal and Scope**: Define purpose, system boundaries, functional unit
2. **Life Cycle Inventory (LCI)**: Quantify all inputs (materials, energy) and outputs (emissions, waste)
3. **Life Cycle Impact Assessment (LCIA)**: Evaluate environmental impacts (GWP, acidification, eutrophication, etc.)
4. **Interpretation**: Analyze results, identify hotspots, make recommendations

### Key LCA Concepts
- **Functional unit**: basis for comparison (e.g., "1 kWh of electricity delivered")
- **System boundaries**: cradle-to-gate, cradle-to-grave, cradle-to-cradle
- **Allocation**: partitioning environmental burdens for multi-product systems
- **Cut-off criteria**: excluding negligible inputs/outputs

### Impact Categories (LCIA)
- **Global Warming Potential (GWP)**: CO₂ equivalents (GWP₁₀₀)
- **Acidification Potential**: SO₂ equivalents
- **Eutrophication Potential**: PO₄³⁻ equivalents
- **Ozone Depletion Potential**: CFC-11 equivalents
- **Human Toxicity Potential**: 1,4-dichlorobenzene equivalents

### LCA Limitations
- Data-intensive and time-consuming
- Assumptions can significantly affect results
- Does not capture all environmental/social impacts
- Geographic and temporal specificity of data

### LCA Tools
- Software: SimaPro, GaBi, openLCA, Umberto
- Databases: ecoinvent, US LCI, ELCD
- Use of LCA software essential for managing large datasets

## Formulas
- GWP = Σ(m_i × GWP_i) for all emissions i
- Carbon footprint expressed as kg CO₂-eq per functional unit
