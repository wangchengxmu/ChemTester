## Key Concepts

**Bioisosteres:** Molecules with different atoms but similar electronic properties/geometry.

Classical: monovalent (CH₃~NH₂~OH~F~Cl), bivalent (vinyl~C=O~C=N), trivalent (alkynyl~CN), ring (benzene~pyridine~thiophene).

Non-classical: geometry/electronics mimics (COOH~tetrazole).

**Specific bioisosteres:**
- Hydrogen → deuterium (kinetic isotope effect, e.g., deucravacitinib) or fluorine (C-F strongest bond in organic chem, e.g., ezetimibe)
- Phenyl rings → heterocycles (Viagra→Levitra), cyclopropane, bicyclohexyl/bicyclopentane (improved metabolic stability, solubility)
- Carboxylic acids → tetrazole (pKa~4.5, 10× more lipophilic, e.g., losartan), difluorophenols, squaric acids
- Amides → ketones, carbamates, ureas, triazoles, oxazoles, trifluoroethylamine, oxetanes; amide transposition

**Structural Alerts:** Aromatic N-H (nitrenium ions → mutagenicity), aromatic O-H (quinones → Michael acceptors), unsubstituted rings (CYP oxidation sites), furans/thiophenes (electrophilic metabolites → hepatotoxicity). Some alerts are dormant (e.g., thiophene in rivaroxaban).

**PAINS:** Pan-Assay INterference compounds yield false positives; require orthogonal assays for validation.
