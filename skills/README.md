# Current Skill Snapshot

`current/L2_principles/` contains the hierarchical chemistry knowledge and
reasoning documents. `current/L3_functions/` contains deterministic chemistry
functions available to the tool runtime. The compact entry point is:

`current/L2_principles/chemtester_compact_problem_solving_skill.md`

`current/snapshot_manifest.json` records the SHA-256 digest of every included
skill file. Benchmark questions and benchmark-recorded answers are not embedded
in the compact entry point by design.
