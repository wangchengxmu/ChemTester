# Process Flow Diagrams

[Source: Foundations of Chemical and Biological Engineering I (Verret), Ch1]

## Core Concept

Process Flow Diagrams (PFDs) are visual representations of chemical processes showing equipment, streams, and flow paths. They are fundamental tools for chemical engineers to communicate process design.

## Diagram Types

### 1. Block Flow Diagram (BFD)
- Simplest representation
- Shows major process units as blocks
- Arrows indicate flow direction

### 2. Process Flow Diagram (PFD)
- More detailed than BFD
- Shows all major equipment
- Includes stream information (flow rates, compositions)
- Standard symbols for equipment

### 3. Piping and Instrumentation Diagram (P&ID)
- Most detailed
- Shows all piping, valves, instruments
- Control system details

## Standard Equipment Symbols

| Equipment | Symbol Description |
|-----------|-------------------|
| Reactor | Rectangle or cylinder |
| Distillation column | Rectangle with trays |
| Heat exchanger | Circle or double-pipe |
| Pump | Circle with triangle |
| Compressor | Circle with blades |
| Tank | Rectangle or cylinder |
| Valve | Bow-tie shape |

## Problem Types

1. **Draw PFD** from process description
2. **Identify equipment** from symbols
3. **Calculate stream flows** from diagram
4. **Design control loops** for P&ID
