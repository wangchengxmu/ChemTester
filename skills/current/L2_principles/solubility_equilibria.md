# Solubility Equilibria

## Concept Overview

Solubility equilibria involve the dissolution and precipitation of slightly soluble ionic compounds, quantified by the solubility product constant (Ksp).

## Key Principles

### Solubility Product (Ksp)
```
MₐXᵦ(s) ⇌ aM^(n+) + bX^(m-)
Ksp = [M^(n+)]^a[X^(m-)]^b
```

### Molar Solubility
- Moles of solute per liter of saturated solution
- Related to Ksp through stoichiometry

### Predicting Precipitation
| Q vs Ksp | Status |
|----------|--------|
| Q < Ksp | Unsaturated |
| Q = Ksp | Saturated |
| Q > Ksp | Supersaturated |

### Common Ion Effect
- Adding a common ion decreases solubility
- Shifts equilibrium toward solid

## Problem-Solving Routes

1. **Write Ksp expression**: Products over reactants (solid omitted)
2. **Calculate Ksp from solubility**: Use ICE table
3. **Calculate solubility from Ksp**: Solve algebraically
4. **Predict precipitation**: Compare Q to Ksp
