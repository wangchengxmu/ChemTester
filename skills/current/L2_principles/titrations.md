# Acid-Base Titrations

## Concept Overview

Titrations determine unknown concentrations by reacting with a standard solution and monitoring pH.

## Key Principles

### Titration Curve Stages
1. **Initial**: pH of analyte solution
2. **Pre-equivalence**: Buffer region (for weak acid/base)
3. **Equivalence point**: Stoichiometric completion
4. **Post-equivalence**: Excess titrant

### Equivalence Point pH
| Titration Type | pH at Equivalence |
|----------------|-------------------|
| Strong + Strong | 7.00 |
| Weak acid + Strong base | > 7 |
| Strong acid + Weak base | < 7 |

### Half-Equivalence Point
- pH = pKa (for weak acid titration)
- [HA] = [A⁻]

### Indicator Selection
- Endpoint pH must match equivalence pH
- Phenolphthalein: 8.2-10.0 (weak acid + strong base)
- Methyl orange: 3.1-4.4 (strong acid + weak base)

## Problem-Solving Routes

1. **Initial pH**: Calculate from acid/base alone
2. **Buffer region**: Use Henderson-Hasselbalch
3. **Equivalence point**: Consider salt hydrolysis
4. **Post-equivalence**: Calculate from excess titrant
