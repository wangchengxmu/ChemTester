## Definition

The **f orbitals** are atomic orbitals with angular momentum quantum number l = 3. They are crucial for understanding the chemistry of lanthanides (4f) and actinides (5f). The unique properties of f orbitals—including their spatial extent, shielding behavior, and angular distribution—give rise to the distinctive chemistry of f-block elements.

## Core Concepts

### 1. f Orbital Shapes and Quantum Numbers

**Quantum numbers:**
- Principal quantum number n: 4 (lanthanides) or 5 (actinides)
- Angular momentum l = 3
- Magnetic quantum number m_l: -3, -2, -1, 0, +1, +2, +3 (7 orbitals)
- Maximum electrons: 14 (2 per orbital)

**Orbital types:**
There are seven f orbitals, often described by their angular distribution:

| Orbital | Angular distribution | Common name |
|---------|---------------------|-------------|
| f_z³ | Along z-axis | Cubic |
| f_xz² | zx plane | |
| f_yz² | yz plane | |
| f_xyz | Eight lobes, all axes | |
| f_z(x²-y²) | zx plane | |
| f_x(x²-3y²) | xy plane | |
| f_y(3x²-y²) | xy plane | |

**Key feature:** f orbitals have complex angular distributions with multiple lobes and nodal planes.

### 2. Spatial Extent: 4f vs 5f

**Critical difference between lanthanides and actinides:**

| Property | 4f (Lanthanides) | 5f (Actinides) |
|----------|------------------|----------------|
| Radial extent | More contracted | More diffuse |
| Overlap with ligands | Poor | Moderate |
| Shielding | Very poor | Poor |
| Covalent bonding | Minimal | Significant |
| Crystal field effects | Weak | Moderate |

**4f orbitals:**
- Deeply buried within the atom
- Radial maximum well inside the 5s²5p⁶ core
- Poor overlap with ligand orbitals
- Result: Ionic bonding dominates

**5f orbitals:**
- More extended radially
- Some overlap with ligand orbitals possible
- Result: Some covalent character in bonding

### 3. Shielding and Penetration

**Shielding order:** s > p > d > f

**f orbitals have the poorest shielding ability:**
- f electrons do not shield each other effectively
- f electrons do not shield outer electrons well
- Results in increasing effective nuclear charge across series

**Penetration:**
- f orbitals have poor penetration toward nucleus
- Shielded by filled s and p subshells of same principal quantum number
- This leads to the lanthanide/actinide contraction

### 4. Electron Configurations

**Building up principle:**

For lanthanides:
```
[Xe] 4f^n 5d^0-1 6s²
```

For actinides:
```
[Rn] 5f^n 6d^0-1 7s²
```

**Irregularities:**
- Energy differences between f and d orbitals are small
- Half-filled (f⁷) and fully-filled (f¹⁴) configurations are stabilized
- Examples: Gd (4f⁷5d¹6s²), Eu (4f⁷6s²), Yb (4f¹⁴6s²)

### 5. Energy Level Diagrams

**Russell-Saunders (LS) coupling:**
- Applicable to lanthanides
- Spin-orbit coupling is significant but not dominant
- Energy levels described by terms: ²S⁺¹L_J

**Intermediate coupling:**
- More appropriate for actinides
- Spin-orbit coupling comparable to electrostatic repulsion
- j-j coupling becomes important for heavy elements

**Term symbols:**
- S = total spin angular momentum
- L = total orbital angular momentum (S, P, D, F, G, H, I...)
- J = total angular momentum

### 6. Spectroscopic Properties

**f-f transitions:**
- Laporte-forbidden (Δl = 0, parity unchanged)
- Weak intensity (ε ~ 1-10 M⁻¹cm⁻¹)
- Sharp, line-like spectra
- Little affected by ligand environment (shielded f orbitals)

**Selection rules:**
- ΔS = 0 (spin selection)
- ΔL = 0, ±1 (orbital selection, but L is not a good quantum number)
- ΔJ = 0, ±1 (J = 0 → J = 0 forbidden)

**Hypersensitive transitions:**
- Certain f-f transitions show unusual intensity dependence on ligand environment
- Examples: ⁴I₁₅/₂ → ⁴G₅/₂ in Nd³⁺

**Charge transfer bands:**
- Laporte-allowed
- Intense absorption (ε ~ 10³-10⁴ M⁻¹cm⁻¹)
- Common in actinides (especially high oxidation states)

### 7. Magnetic Properties

**Lanthanide magnetic moments:**
- Calculated considering spin-orbit coupling
- Formula: μ_eff = g_J√[J(J+1)] μ_B
- g_J = Landé g-factor

**g-factor formula:**
```
g_J = 1 + [J(J+1) + S(S+1) - L(L+1)] / [2J(J+1)]
```

**Ground state terms (Hund's rules):**

| Ion | Config | Ground term | g_J | μ_eff (calc) |
|-----|--------|-------------|-----|--------------|
| Ce³⁺ | 4f¹ | ²F₅/₂ | 6/7 | 2.54 |
| Pr³⁺ | 4f² | ³H₄ | 4/5 | 3.58 |
| Nd³⁺ | 4f³ | ⁴I₉/₂ | 8/11 | 3.62 |
| Eu³⁺ | 4f⁶ | ⁷F₀ | 0 | 0 (but J-mixing) |
| Gd³⁺ | 4f⁷ | ⁸S₇/₂ | 2 | 7.94 |
| Tb³⁺ | 4f⁸ | ⁷F₆ | 3/2 | 9.72 |
| Dy³⁺ | 4f⁹ | ⁶H₁₅/₂ | 4/3 | 10.65 |
| Ho³⁺ | 4f¹⁰ | ⁵I₈ | 5/4 | 10.61 |
| Er³⁺ | 4f¹¹ | ⁴I₁₅/₂ | 6/5 | 9.59 |
| Tm³⁺ | 4f¹² | ³H₆ | 7/6 | 7.56 |

**Actinide magnetic moments:**
- More complex due to stronger spin-orbit coupling
- Quenching of orbital angular momentum is incomplete
- Temperature-dependent behavior more pronounced

### 8. Crystal Field Effects

**Weak crystal field limit:**
- f orbitals are shielded from ligand field
- Crystal field splitting is small (100-1000 cm⁻¹)
- Compare to d-block: 10,000-20,000 cm⁻¹

**Consequences:**
- Ligand field stabilization energy (LFSE) is minimal
- Coordination geometry determined by sterics, not electronic effects
- Magnetic and spectroscopic properties relatively insensitive to ligands

**Crystal field splitting patterns:**

For cubic (O_h) symmetry, 7 f orbitals split into:
- a₂u (1 orbital)
- t₁u (3 orbitals)
- t₂u (3 orbitals)

### 9. Comparison: 4f vs 5f Chemistry

| Aspect | 4f (Lanthanides) | 5f (Actinides) |
|--------|------------------|----------------|
| Orbital extent | Contracted | Diffuse |
| Ligand overlap | Minimal | Moderate |
| Bonding type | Ionic | Ionic + covalent |
| Crystal field effects | Weak | Moderate |
| Oxidation states | +3 dominant | Multiple accessible |
| Magnetic behavior | Predictable (LS coupling) | Complex |
| Spectroscopy | Sharp f-f lines | Broader, more intense |
| Coordination chemistry | Electrostatic | Some covalent character |

## Key Formulas

### Effective Magnetic Moment
```
μ_eff = g_J√[J(J+1)] μ_B
```

### Landé g-factor
```
g_J = 1 + [J(J+1) + S(S+1) - L(L+1)] / [2J(J+1)]
```

### Spin-only moment (for comparison)
```
μ_SO = √[4S(S+1)] μ_B = √[n(n+2)] μ_B
```
where n = number of unpaired electrons

### Crystal field splitting (qualitative)
```
Δ_CF (f orbitals) << Δ_CF (d orbitals)
```

## Applications

1. **Magnetic materials:** f-element compounds for high-performance magnets
2. **Optical materials:** Sharp f-f transitions for lasers and phosphors
3. **Nuclear chemistry:** f-orbital involvement in nuclear properties
4. **Catalysis:** f-element catalysts (Ce, La)
5. **Sensors:** f-element luminescence for detection
