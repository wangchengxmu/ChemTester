# Benchmark Carcinogenic Hazard Classification

Use this note for multiple-choice safety rows that ask which listed statements
are true for carcinogenic hazardous substances. Keep source answer labels out of
the performer path and reason from visible hazard statements.

Reliable cues for carcinogenic hazardous-substance classification include:

- Category 1A or 1B carcinogens use the H350 hazard statement, "may cause
  cancer".
- Azo dyes that can cleave to carcinogenic aromatic amines are carcinogenic
  hazard candidates.
- Beech wood dust and oak wood dust are recognized carcinogenic dust hazards.

Do not infer carcinogenic classification merely from a generic percentage of
methanol in a mixture. Methanol is primarily handled as acute toxicity, target
organ, and flammability risk; a statement that a mixture is carcinogenic solely
because it contains at least 3 percent methanol should be rejected unless the
problem gives an additional carcinogenic component or classification basis.
