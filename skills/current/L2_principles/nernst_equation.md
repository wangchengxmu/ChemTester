# Nernst Equation

## Concept Overview

The Nernst equation relates cell potential to concentration.

## Key Principles

### Nernst Equation
```
E_cell = E°_cell - (0.0592 V / n) log Q
```

### Relationships
- ΔG° = -nFE°_cell
- E°_cell = (0.0592 V / n) log K
- K = 10^(nE°/0.0592)
