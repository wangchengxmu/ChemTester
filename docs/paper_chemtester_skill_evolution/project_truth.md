# Project Truth

## Claim scope

- The work builds and evaluates an external chemistry memory and skill registry. It does not train model weights.
- The intended book scope is all named works on the eight curated Chemistry LibreTexts shelves.
- The retained source records do not establish complete reading of that universe.
- The sealed 400-question acceptance suite was not used for skill development and is not inspected in this manuscript audit.
