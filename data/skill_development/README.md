# Skill-Development Question Families

`canonical_families_3086.jsonl` contains one record for each canonical family
processed by the retrospective open-benchmark loop. The source archive held
7,381 records; question-family deduplication retained 3,086 representatives and
skipped 4,295 variants in 1,876 duplicate groups.

Each included record preserves its source repository, source question ID,
family identifier, duplicate IDs, and problem payload. GPQA-derived records
contain only provenance and SHA-256 hashes because their upstream access terms
request that examples not be posted online.

These records were used to develop external memory, reasoning strategies, and
deterministic tools. They were not used for model-weight training.
